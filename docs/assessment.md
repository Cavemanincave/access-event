# Оценка ИС AccessEvent и направления модернизации

## 1. SWOT-АНАЛИЗ
- **Сильные стороны (Strengths):** Инклюзивность заложена на уровне архитектуры БД; полная автоматизация CI/CD проверок; контейнеризация Docker.
- **Слабые стороны (Weaknesses):** Тесты используют SQLite, а продакшен — PostgreSQL; нет системы веб-пушей.
- **Возможности (Opportunities):** Расширение аудитории за счет уникального доступного интерфейса; получение грантов на социальные ИТ-проекты.
- **Угрозы (Threats):** Изменение международных стандартов доступности (обновления WCAG); риски утечки JWT-сессий.

## 2. Заключение о готовности
Информационная система полностью готова к опытной эксплуатации. Основные бизнес-сценарии покрыты автотестами на 100%, развёртывание инфраструктуры стандартизировано.

## 3. Направления модернизации
1. **Браузерные Push-уведомления:** Интеграция Web Push API для отправки визуальных уведомлений пользователям даже при закрытой вкладке сайта.
2. **ИИ-субтитры:** Интеграция с Whisper API для автоматического перевода речи спикеров на мероприятиях в текстовые субтитры в реальном времени.
