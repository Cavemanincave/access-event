# Тезисы выступления: AccessEvent

[0:00–0:30] Добрый день! Я защищаю проект AccessEvent — платформу для организации мероприятий, доступную людям с нарушениями слуха. Цель проекта — перенос всех критических аудиосигналов в визуальный канал взаимодействия (цветные уведомления, чат, текстовая индикация статусов).

[0:30–1:30] В ходе анализа требований было сформировано 15 функциональных и 8 нефункциональных требований, включая стандарт доступности WCAG 2.1 AA. Основной стейкхолдер — участник с нарушением слуха.

[1:30–3:00] Архитектура системы состоит из трех слоев: клиентский слой (HTML/CSS/JS), серверная логика на Flask с JWT-авторизацией и слой данных PostgreSQL. База данных спроектирована до уровня 3НФ и включает 7 таблиц. Пароли пользователей надежно хешируются.

[3:00–5:00] Тестирование системы проводилось с помощью pytest. Написано 14 автотестов, полностью покрывающих модели и API эндпоинты. В ходе ручного тестирования зафиксировано 3 бага, критические дефекты успешно исправлены. Все пайплайны CI/CD на GitHub Actions работают стабильно. Спасибо за внимание!
