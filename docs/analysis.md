# Анализ сущностей системы (Entities)

В данном документе представлены ключевые сущности базы данных для системы управления мероприятиями.

## Сущность: User (Пользователь)

| Поле | Тип данных | Описание | Обязательное |
| --- | --- | --- | --- |
| id | Integer | Первичный ключ | Да |
| username | String | Имя пользователя | Да |
| email | String | Электронная почта | Да |
| password_hash | String | Хэш пароля | Да |
| role | String | Роль (admin/user) | Да |

## Сущность: Event (Мероприятие)

| Поле | Тип данных | Описание | Обязательное |
| --- | --- | --- | --- |
| id | Integer | Первичный ключ | Да |
| title | String | Название события | Да |
| description | Text | Описание | Нет |
| date | DateTime | Дата проведения | Да |
| slots | Integer | Количество мест | Да |

## Сущность: Registration (Регистрация)

| Поле | Тип данных | Описание | Обязательное |
| --- | --- | --- | --- |
| id | Integer | Первичный ключ | Да |
| user_id | Integer | Внешний ключ на User | Да |
| event_id | Integer | Внешний ключ на Event | Да |
| created_at | DateTime | Дата регистрации | Да |
