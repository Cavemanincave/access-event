# Заинтересованные стороны проекта (Stakeholders)

В данном документе описаны ключевые участники и заинтересованные стороны, чьи требования и интересы учитываются при разработке бэкенд-системы управления доступом на мероприятия.

## 1. Конечные пользователи (Посетители)
* **Интересы:** Быстрая и стабильная регистрация на мероприятия, получение билетов или QR-кодов без задержек.
* **Требования:** Безопасность персональных данных, интуитивно понятный интерфейс взаимодействия с API.

## 2. Организаторы мероприятий
* **Интересы:** Контроль количества регистраций, управление списками участников в реальном времени.
* **Требования:** Надежные инструменты для проверки прав доступа, выгрузка аналитики и отчетов по посещаемости.

## 3. Администраторы платформы
* **Интересы:** Стабильная работа всей системы бэкенда, отсутствие сбоев при пиковых нагрузках.
* **Требования:** Разграничение ролей безопасности (RBAC), подробное логирование действий пользователей и системных ошибок.
