# Баг-репорты AccessEvent
## BUG-01. [Major] Повторная регистрация с тем же email возвращает 500
- Серьёзность: Major | Приоритет: P2
- Шаги воспроизведения: Отправить POST /api/register с одинаковым email два раза подряд.
- Фактический результат: 500 Internal Server Error (UNIQUE-конфликт в базе данных).
- Ожидаемый результат: 400 Bad Request с валидным JSON-сообщением.
- Статус: Исправлен (в routes/auth.py добавлена пре-проверка `User.query.filter_by(email=email).first()`).

## BUG-02. [Major] Регистрация принимает email без символа @
- Серьёзность: Major | Приоритет: P2
- Шаги воспроизведения: POST /api/register с телом `{"email": "invalid-mail"}`.
- Фактический результат: 201 Created, пользователь успешно занесён в систему.
- Ожидаемый результат: 400 Bad Request из-за нарушения формата email.
- Статус: Исправлен (добавлен валидатор строк email).

## BUG-03. [Minor] Бейдж статуса регистрации плохо читается в тёмной теме
- Серьёзность: Minor | Приоритет: P3
- Шаги воспроизведения: Переключить браузер в тёмный режим и открыть личный кабинет.
- Фактический результат: Жёлтый цвет бейджа `pending` сливается со светлым фоном карточки.
- Ожидаемый результат: Четкая контрастность текста по стандарту WCAG 2.1 AA.
- Статус: Не исправлен (перенесено в бэклог Дня 6, требует изменения стилей CSS).
