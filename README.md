# Access Event Project

## Описание проекта
Это полноценное бэкенд-приложение, предназначенное для автоматизации процессов регистрации и управления доступом пользователей на различные мероприятия. Проект реализует гибкую ролевую модель доступа и безопасность персональных данных.

## Технологический стек
* **Язык программирования:** Python 3.11
* **Фреймворк:** Flask / FastAPI
* **Безопасность:** JWT-токены, хэширование паролей

## Инструкция по локальному запуску
1. Склонируйте репозиторий на свой компьютер.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
3. Установите все необходимые зависимости из файла:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите основное приложение:
   ```bash
   python app.py
   ```
